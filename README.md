# Hedge Fund Performance Analysis | Python Replication

## Project Overview

This project replicates Exhibit 1 from *Do Hedge Funds Hedge?* by Clifford Asness, Robert Krail, and John Liew (2001), using Python to analyze historical hedge fund returns and compare investment performance across strategies.

## Objectives

- Replicate published hedge fund performance statistics.
- Calculate excess returns, annualized volatility, Sharpe ratios, and correlations.
- Evaluate hedge fund performance relative to the S&P 500.
- Compare independently calculated results with the authors' published findings.

## Tools & Technologies

- **Python:** Financial calculations and analysis
- **pandas:** Data manipulation and performance statistics
- **NumPy:** Numerical calculations
- **Jupyter Notebook:** Interactive financial analysis
- **XlsxWriter:** Formatted Excel reporting

## Methodology

Historical monthly hedge fund returns are analyzed to calculate key performance and risk metrics. Results are organized into a replication exhibit and compared against the published study to identify differences.

## Outputs

- Jupyter Notebook containing the analysis
- Recreated hedge fund performance exhibit
- Excel export of the published, replicated, and comparative results

## Reference

Asness, C. S., Krail, R. J., & Liew, J. M. (2001). *Do Hedge Funds Hedge?* The Journal of Portfolio Management.
